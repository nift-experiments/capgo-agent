 ## Import [Section titled “Import”](#import) 
```typescript
import { ScreenRecorder } from '@capgo/capacitor-screen-recorder';
```
 ## API Overview [Section titled “API Overview”](#api-overview) ### `start` [Section titled “start”](#start) Start recording the device screen. Initiates screen recording with optional audio capture. The user will be prompted to grant screen recording permissions if not already granted. On iOS, the system recording UI will be displayed. On Android, the recording starts immediately after permission is granted. 
```typescript
import { ScreenRecorder } from '@capgo/capacitor-screen-recorder';


// Start recording without audio
await ScreenRecorder.start();


// Start recording with audio
await ScreenRecorder.start({ recordAudio: true });
```
 ### `stop` [Section titled “stop”](#stop) Stop the current screen recording. Stops the active screen recording and saves the video to the device’s camera roll or gallery. On iOS, the system will show a preview of the recording. On Android, the video is saved directly to the gallery. 
```typescript
import { ScreenRecorder } from '@capgo/capacitor-screen-recorder';


await ScreenRecorder.stop();
console.log('Recording saved to gallery');
```
