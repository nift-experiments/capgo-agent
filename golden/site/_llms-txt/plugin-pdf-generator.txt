# Getting Started

> Install @capgo/capacitor-pdf-generator and start using its current Capacitor API.

## Install [Section titled “Install”](#install) You can use our AI-Assisted Setup to install the plugin. Add the Capgo skills to your AI tool using the following command: 
```bash
npx skills add https://github.com/Cap-go/capgo-skills --skill capacitor-plugins
```
 Then use the following prompt: 
```text
Use the `capacitor-plugins` skill from `Cap-go/capgo-skills` to install the `@capgo/capacitor-pdf-generator` plugin in my project.
```
 If you prefer Manual Setup, install the plugin by running the following commands and follow the platform-specific instructions below: 
```bash
bun add @capgo/capacitor-pdf-generator
bunx cap sync
```

 ## API Overview [Section titled “API Overview”](#api-overview) ### `fromURL` [Section titled “fromURL”](#fromurl) Generates a PDF from the provided URL. 
```typescript
import { PdfGenerator } from '@capgo/capacitor-pdf-generator';


const result = await PdfGenerator.fromURL({ url: 'https://example.com' });

```
 ### `fromData` [Section titled “fromData”](#fromdata) Generates a PDF from a raw HTML string. 
```typescript

```
