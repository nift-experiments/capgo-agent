# Getting Started

> Install @capgo/capacitor-ivs-player and start using its current Capacitor API.

## Install [Section titled “Install”](#install) You can use our AI-Assisted Setup to install the plugin. Add the Capgo skills to your AI tool using the following command: 
```bash
npx skills add https://github.com/Cap-go/capgo-skills --skill capacitor-plugins
```
 Then use the following prompt: 
```text
Use the `capacitor-plugins` skill from `Cap-go/capgo-skills` to install the `@capgo/capacitor-ivs-player` plugin in my project.
```
 If you prefer Manual Setup, install the plugin by running the following commands and follow the platform-specific instructions below: 
```bash
bun add @capgo/capacitor-ivs-player
bunx cap sync
```
