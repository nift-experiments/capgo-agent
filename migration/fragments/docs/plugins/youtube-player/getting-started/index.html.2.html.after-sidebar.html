Import

Section titled “Import”

Fix YouTube Referer Blocking in the Main WebView

Section titled “Fix YouTube Referer Blocking in the Main WebView”

If YouTube works inside the plugin but fails when the same app loads YouTube pages, embeds, or APIs through Capacitor’s main WebView, enable patchRefererHeader in your Capacitor config.

When enabled, the plugin patches Capacitor during sync/update so intercepted YouTube requests include a valid Referer header.

  • Only youtube.com, youtube-nocookie.com, and youtu.be requests are affected.
  • Requests that already define a Referer header keep their original value.
  • refererHeader is optional and defaults to https://www.youtube.com.
  • Supported on Capacitor 8.x for installed iOS and Android platforms.

API Overview

Section titled “API Overview”

initialize

Section titled “initialize”

Initialize a new YouTube player instance.

destroy

Section titled “destroy”

Destroy a player instance and free resources.

stopVideo

Section titled “stopVideo”

Stop video playback and cancel loading. Use this sparingly - pauseVideo() is usually preferred.

playVideo

Section titled “playVideo”

Play the currently cued or loaded video. Final player state will be PLAYING (1).

pauseVideo

Section titled “pauseVideo”

Pause the currently playing video. Final player state will be PAUSED (2), unless already ENDED (0).

seekTo

Section titled “seekTo”

Seek to a specific time in the video. If player is paused, it remains paused. If playing, continues playing.

loadVideoById

Section titled “loadVideoById”

Load and play a video by its YouTube ID.

cueVideoById

Section titled “cueVideoById”

Cue a video by ID without playing it. Loads thumbnail and prepares player, but doesn’t request video until playVideo() called.

loadVideoByUrl

Section titled “loadVideoByUrl”

Load and play a video by its full URL.

cueVideoByUrl

Section titled “cueVideoByUrl”

Cue a video by URL without playing it.

cuePlaylist

Section titled “cuePlaylist”

Cue a playlist without playing it. Loads playlist and prepares first video.

loadPlaylist

Section titled “loadPlaylist”

Load and play a playlist.

nextVideo

Section titled “nextVideo”

Play the next video in the playlist.

previousVideo

Section titled “previousVideo”

Play the previous video in the playlist.

playVideoAt

Section titled “playVideoAt”

Play a specific video in the playlist by index.

mute

Section titled “mute”

Mute the player audio.

unMute

Section titled “unMute”

Unmute the player audio.

isMuted

Section titled “isMuted”

Check if the player is currently muted.

setVolume

Section titled “setVolume”

Set the player volume level.

getVolume

Section titled “getVolume”

Get the current player volume level. Returns volume even if player is muted.

setSize

Section titled “setSize”

Set the player dimensions in pixels.

getPlaybackRate

Section titled “getPlaybackRate”

Get the current playback rate.

setPlaybackRate

Section titled “setPlaybackRate”

Set the playback speed.

getAvailablePlaybackRates

Section titled “getAvailablePlaybackRates”

Get list of available playback rates for current video.

setLoop

Section titled “setLoop”

Enable or disable playlist looping. When enabled, playlist will restart from beginning after last video.

setShuffle

Section titled “setShuffle”

Enable or disable playlist shuffle.

getVideoLoadedFraction

Section titled “getVideoLoadedFraction”

Get the fraction of the video that has been buffered. More reliable than deprecated getVideoBytesLoaded/getVideoBytesTotal.

getPlayerState

Section titled “getPlayerState”

Get the current state of the player.

getAllPlayersEventsState

Section titled “getAllPlayersEventsState”

Get event states for all active players. Useful for tracking multiple player instances.

getCurrentTime

Section titled “getCurrentTime”

Get the current playback position in seconds.

toggleFullScreen

Section titled “toggleFullScreen”

Toggle fullscreen mode on or off.

getPlaybackQuality

Section titled “getPlaybackQuality”

Get the current playback quality.

setPlaybackQuality

Section titled “setPlaybackQuality”

Set the suggested playback quality. Actual quality may differ based on network conditions.

getAvailableQualityLevels

Section titled “getAvailableQualityLevels”

Get list of available quality levels for current video.

getDuration

Section titled “getDuration”

Get the duration of the current video in seconds.

getVideoUrl

Section titled “getVideoUrl”

Get the YouTube.com URL for the current video.

getVideoEmbedCode

Section titled “getVideoEmbedCode”

Get the embed code for the current video. Returns HTML iframe embed code.

getPlaylist

Section titled “getPlaylist”

Get array of video IDs in the current playlist.

getPlaylistIndex

Section titled “getPlaylistIndex”

Get the index of the currently playing video in the playlist.

getIframe

Section titled “getIframe”

Get the iframe DOM element for the player. Web platform only.

addEventListener

Section titled “addEventListener”

Add an event listener to the player. Web platform only.

removeEventListener

Section titled “removeEventListener”

Remove an event listener from the player. Web platform only.
