Median vs Capgo: managed lock-in or open Capacitor?

Median is convenient when you want to hand the app to a managed platform. Capacitor plus Capgo keeps the mobile app, update path, plugins, and hosting choices in your hands.

Verdict Choose Median if you want to outsource the mobile shell and accept platform dependency. Choose Capgo with Capacitor if you want web-to-mobile delivery without giving up ownership or exit options.

Honest take

Where Median is the better choice

No tool fits every team. These are the cases where we would point you to the other option.

You have no mobile developers

On Business plans, starting at $7,200/year, the Median team builds, publishes, and maintains your iOS and Android apps. [1]

Your site is built with a no-code tool

Median displays any website in its native shell, including WordPress, Webflow, Wix, and Bubble sites, with no build step on your side. [1]

You want to try for free

The Median Free license lets you build and test a non-commercial app at no cost, with a Powered by Median.co message on launch. [4]

Migration path

Move from Median to Capacitor and Capgo

Median has no export to Capacitor, so this is a rebuild of the native layer around the same web app. Your web code stays as it is.

  1. Wrap your web app with Capacitor

    Add @capacitor/core and @capacitor/cli to your web project, run npx cap init, then add the iOS and Android platforms.

  2. Swap bridge calls for plugins

    Replace Median JavaScript Bridge calls with Capacitor plugins for push notifications, biometrics, deep links, and the other native features you use.

  3. Install the Capgo updater

    Run npx @capgo/cli@latest init. It adds the app to Capgo, installs @capgo/capacitor-updater, and walks you through the first bundle upload.
