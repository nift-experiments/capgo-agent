Honest take

Where Expo Application Services is the better choice

No tool fits every team. These are the cases where we would point you to the other option.

Your app is React Native

Expo and EAS are built for React Native. If your mobile UI is already React Native, keep EAS; Capgo does not update React Native apps. [2]

You need a free plan

The Expo Free plan includes 1,000 update MAU and up to 15 Android and 15 iOS builds. Capgo has a 14-day trial but no free plan. [1]

You want web hosting too

EAS Hosting deploys Expo Router web projects and API routes. Capgo does not host websites. [6]

Migration path

From web app to iOS and Android with Capgo

There is no code migration from React Native to Capacitor. The path is to keep your web app and wrap it, then ship it with Capgo.

  1. Wrap your web app with Capacitor

    Add @capacitor/core and @capacitor/cli to your web project, run npx cap init, then add the iOS and Android platforms.

  2. Install the Capgo updater

    Run npx @capgo/cli@latest init. It adds the app to Capgo, installs @capgo/capacitor-updater, and walks you through the first bundle upload.

  3. Build native binaries

    Run npx @capgo/cli@latest build request --platform ios (or android) to build and sign binaries in the cloud. A typical build takes 2–3 minutes.
