Before you switch

What changes for the three most used plugins

Identity Vault to Native Biometric

Native Biometric stores credentials in the iOS Keychain or Android Keystore, and protected reads need Face ID, Touch ID, or Android biometrics. Timeout locks and privacy screens move to your app code. Custom-passcode and memory-only vault modes are not supported.

Identity Vault migration guide

Auth Connect to Social Login

Social Login signs users in with Google, Apple, Facebook, Twitter, and generic OAuth2 providers. List your providers and redirect URLs first, and keep refresh tokens in a secure store.

Auth Connect migration guide

Secure Storage to SQLite

Use Data Storage SQLite for key-value data with optional encryption, or Fast SQL for large datasets and full SQL. On first launch, read your values from Ionic Secure Storage and write them to the new store.

Secure Storage migration guide

How it works

How teams move off Ionic Enterprise plugins

Replace one plugin at a time. Each swap is a native change, so it ships in a store release.

  1. 1

    List the Ionic packages you use

    Find every @ionic-enterprise package in your app and match it to its Capgo replacement in the table above.

    grep "@ionic-enterprise" package.json
    See replacements and guides
  2. 2

    Install the replacement and sync

    Add the Capgo plugin and sync the native projects. Then update your calls to the new API using the plugin docs.

    npm install @capgo/capacitor-native-biometric
npx cap sync
    Native Biometric docs
  3. 3

    Move stored data on first launch

    Read credentials and values from the Ionic plugin once, write them with the Capgo plugin, and keep your lock and timeout policy in app code.

    Secure Storage migration guide
  4. 4

    Remove the Ionic package and release

    Uninstall the Ionic package, sync, and ship a store release. If you also used Appflow, the Appflow guide covers live updates and builds.

    npm uninstall @ionic-enterprise/identity-vault
npx cap sync
    Appflow to Capgo migration guide

FAQ

Ionic Enterprise plugin questions

What teams ask before they replace Ionic's commercial plugins.

Are the Capgo plugins free?

Yes. They are open source under MPL-2.0, and you can use them without a Capgo plan. A plan adds priority handling of your plugin bug reports, plus live updates and native builds.

Browse Capgo plugins

Is Native Biometric a full replacement for Identity Vault?

It replaces the credential vault: save, check, read, and delete credentials with biometric-protected reads. Timeout locks and privacy screens become app code, and custom-passcode and memory-only modes are not supported.

Identity Vault migration guide

Do we have to migrate data our users already stored?

Yes. On first launch after the update, read values from the Ionic plugin, write them with the Capgo plugin, then remove the Ionic plugin in a later release.

Secure Storage migration guide

We also use Appflow. Can Capgo replace it?

Yes. Replace the Appflow live updates SDK with @capgo/capacitor-updater and call notifyAppReady(). Existing Appflow projects can run until 31 December 2027, so you can plan the switch around your release schedule.

Appflow to Capgo migration guide

Can Capgo run the migration for us?

Yes. We scope Ionic Enterprise plugin migrations as fixed-price projects after a free discovery call. The code we write is assigned to your company.
