For software agents

If you are an agent integrating Capgo, start with llms.txt for when-to-use guidance, then openapi.json for the public REST API at https://api.capgo.app. Authenticate REST calls with the x-api-key header. The Streamable HTTP MCP server is /mcp; the manifest is /.well-known/mcp.json. Authenticated account mutations (upload, channel change, native build) still use npx @capgo/cli@latest mcp after login. Human-readable docs live at /docs/ and /docs/public-api/.
