Release control in your pocket

Built for CapacitorJS apps when a laptop is not open

The mobile app is not just a companion view. It is the fastest way to prove a live update on-device, keep QA previews organized, and check whether a native build is still moving.

Preview a build on the device that will run it

Open a bundle or channel preview from the dashboard or CLI, scan the QR code, and apply it directly inside the Capgo app for a real-device check.

Keep multiple previews ready for QA

Saved previews let testers switch between build candidates, update a preview, delete stale ones, and return to the main app without rebuilding.

Follow native builds away from your desk

The build view shows platform, build mode, status, duration, output details, and errors so you can react before the release window closes.

See compatibility before choosing the release path

Compatibility events surface dependency changes, unresolved devices, rollback options, and the moment a native rebuild is the safer path.

Manage live updates on the go

Check apps, channels, bundles, and current release state from your phone when production needs a fast decision.

Share CLI and dashboard QR previews

Send the same QR code or deep link to your team, QA group, or selected users so they can test the exact build on their own device.

Preview workflow

From release candidate to real-device proof

Capgo preview links move from CLI or dashboard to the mobile app without a handoff. Share a QR code, let teammates or selected users test, and decide with the same release context.

1

Create a shareable preview

Generate a bundle or channel preview from Capgo, the dashboard, or the CLI QR preview flow.

2

Share it with testers

Send the QR code or deep link to teammates, QA, or selected users, then let them start the preview in the Capgo app.

3

Test and decide

Switch saved previews, inspect compatibility, watch build status, and either ship OTA or prepare a native build.
