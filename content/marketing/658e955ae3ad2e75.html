Honest take

Where Microsoft CodePush is the better choice

No tool fits every team. These are the cases where we would point you to the other option.

Your app is React Native

Capgo updates Capacitor, Cordova, and Electron apps, not React Native. React Native teams can look at EAS Update or run the standalone CodePush server. [2]

You want to run it all yourself

The standalone server has no license fee. You take on hosting, security patches, and maintenance, with no vendor support. [2]

Migration path

Leave CodePush / App Center

Export your release habits, remove CodePush SDK wiring, and point Capacitor builds at Capgo channels. Our migration hub links App Center blog posts and step-by-step docs.

  1. Remove CodePush

    Remove the CodePush SDK and its deployment keys from your app, and drop the App Center release step from CI.

  2. Install the Capgo updater

    Run npx @capgo/cli@latest init in your Capacitor project. It installs @capgo/capacitor-updater and walks you through the first bundle upload.

  3. Map deployments to channels

    Recreate your Staging and Production deployments as Capgo channels, then upload with npx @capgo/cli@latest bundle upload --channel=production.
