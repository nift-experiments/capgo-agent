How a solo developer ships with Capgo

The whole setup for one person and one app. Every command below is from the Capgo docs.

  1. 1

    Set up the app

    The init command walks you through adding the updater plugin, building, and uploading your first bundle.

    npx @capgo/cli@latest init
    Quickstart
  2. 2

    Upload on every push to main

    Add a Capgo step to your GitHub Actions workflow and store your API key as CAPGO_TOKEN in the repository secrets.

    - name: Deploy to Capgo
  run: npx @capgo/cli@latest bundle upload --channel production
  env:
    CAPGO_TOKEN: ${{ secrets.CAPGO_TOKEN }}
    GitHub Actions guide
  3. 3

    Let failed bundles roll back

    Call notifyAppReady() when the app starts. If a new bundle does not call it within 10 seconds, the device goes back to the last working version.

    import { CapacitorUpdater } from '@capgo/capacitor-updater'

CapacitorUpdater.notifyAppReady()
    notifyAppReady() docs
  4. 4

    Build iOS without a Mac

    Save your signing credentials once. Capgo Build compiles the app on Capgo's Mac machines, usually in 2–3 minutes.

    npx @capgo/cli@latest build credentials save --appId com.example.app --platform ios
npx @capgo/cli@latest build request com.example.app --platform ios
    iOS build docs

Solo developer questions

What people shipping an app on their own ask before trying Capgo.

How much does Capgo cost for one developer?

Plans start at $12/month billed yearly, or $14 billed monthly. You start with a 14-day free trial, no credit card needed. There is no free plan.

See pricing

Do I need a Mac to build the iOS app?

No. Capgo Build runs iOS builds on Capgo's Mac machines and can upload the result to App Store Connect. You save your signing credentials once with the CLI.

iOS build docs

What if a bundle breaks and I am not around?

If a new bundle does not call notifyAppReady() within 10 seconds, the device goes back to the last working version on its own. Later, you can point the channel back to an earlier bundle.

notifyAppReady() docs

Can my AI coding assistant use Capgo?

Yes. Run npx @capgo/cli mcp to start a local MCP server your assistant can call to upload bundles, manage channels, and request builds. The Capgo skills add Capgo-specific instructions to agents like Claude Code, Codex, and Cursor.

MCP server docs

What can a live update not change?

Native code, new native plugins, permissions, and app icons. Those live in the binary and need a store release. Capgo checks bundle compatibility with the native side before upload.

Native compatibility docs
