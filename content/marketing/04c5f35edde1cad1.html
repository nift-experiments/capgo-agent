Honest take

Where VoltBuilder is the better choice

No tool fits every team. These are the cases where we would point you to the other option.

You only need builds

VoltBuilder is a build service only. If you ship every change through the stores and never need live updates, it covers the job. [2]

Your app is a Cordova project

VoltBuilder supports Cordova projects and says you can extend apps with over a thousand Apache Cordova plugins. [2]

You need free Android debug builds

The free VoltBuilder tier builds Android debug apps, 4 builds a day with uploads up to 10 MB. [1]

Migration path

Add Capgo to a VoltBuilder project

You can keep VoltBuilder for builds and add Capgo live updates, or move builds to Capgo Builder as well.

  1. Install the Capgo updater

    Run npx @capgo/cli@latest init. It adds the app to Capgo, installs @capgo/capacitor-updater, and walks you through the first bundle upload.

  2. Upload from your CI

    Add npx @capgo/cli@latest bundle upload after your web build so each change reaches users without a new store release.

  3. Build native binaries

    Run npx @capgo/cli@latest build request --platform ios (or android) to build and sign binaries in the cloud. A typical build takes 2–3 minutes.
