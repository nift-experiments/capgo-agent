How it works

How agencies ship client apps with Capgo

A setup you can repeat for each new client. Every command below is from the Capgo CLI docs.

  1. 1

    Create an organization for the client

    Each client gets its own organization, plan, and member list. Add your team with a group, and the client's people with their own roles.

    npx @capgo/cli@latest organization add --name "Client A" --email mobile@client-a.com
    Roles reference
  2. 2

    Give the client's CI its own API key

    Create an API key limited to that client's app, with the App Uploader role and an expiry date. Store it in the client's CI secrets.

    # In Client A's pipeline, with Client A's key
npx @capgo/cli@latest bundle upload --channel staging --apikey "$CAPGO_TOKEN"
    API key docs
  3. 3

    Let the client review, then promote

    Point the client's test phones at the staging channel with device overrides. When they approve, link the same bundle to production.

    npx @capgo/cli@latest channel set production com.client-a.app --bundle 1.4.2
    Channels docs
  4. 4

    Hand the app over

    Invite the client's admins, let your CI keys expire, and transfer the app to the client's organization from the app settings. Only a Super Admin can transfer an app.

FAQ

Agency questions

What agencies usually ask before moving client apps to Capgo.

Can I keep each client's apps and data separate?

Yes. Create one organization per client. Members, apps, API keys, plans, and audit logs belong to that organization, and you switch between organizations from the sidebar.

Organization docs

Can the client pay for their own plan?

Yes. A plan applies only to the organization it was bought for. Give the client's finance contact the Billing Manager role so they can manage payment and invoices without access to apps.

Billing docs

Can a contractor work on only one client app?

Yes. Give them an app-scoped role such as App Developer or App Uploader on that app. Their upload and device rights stay limited to that app.

Roles reference

How do we hand an app over at the end of a contract?

A Super Admin can transfer the app to another organization they belong to, such as one the client owns. You can also invite the client's admins to the existing organization and remove your team afterwards.

App settings and transfer docs

What can we change without a store release?

Live updates change the web layer: JavaScript, HTML, CSS, and assets. New native plugins, permissions, or native code need a new binary and store review. Capgo Build can produce those binaries in the cloud.

Native compatibility docs
