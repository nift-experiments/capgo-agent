Microsoft CodePush — legacy status

CodePush pioneered JavaScript OTA updates for mobile. The hosted service is gone; Capacitor teams need a successor.

What CodePush did well

Free tier, Microsoft infrastructure, and simple promote/rollback flows for JavaScript bundles — especially for React Native.

Retirement

App Center CodePush shutdown pushed teams to self-host, change stacks, or adopt vendors built for their framework.

Capacitor path

Capgo is built for Capacitor live updates with signing, channels, and analytics — not a drop-in CodePush SDK replacement.
