Model Context Protocol (MCP) on Capgo

Connect AI agents to Capgo documentation, OpenAPI, and when-to-use guidance — without replacing the CLI MCP server for uploads and builds.

Public Streamable HTTP server

GET /.well-known/mcp.json for the manifest. POST JSON-RPC to /mcp for tools like capgo_when_to_use, capgo_get_openapi, and capgo_list_docs.

Browsers requesting HTML on /mcp see this page. Clients sending Accept: text/event-stream receive the SSE handshake. API clients should POST with application/json.

Endpoint: POST https://capgo.app/mcp

Authenticated CLI MCP

Account mutations — bundle upload, channel changes, native builds — run through npx @capgo/cli@latest mcp after login. See /docs/cli/reference/mcp/ and /skills/.

npx @capgo/cli@latest mcp
