## Reactive exception: docs search

Category 4 is Algolia DocSearch 3.9.0, isolated within `sl-doc-search`, loaded asynchronously on docs routes using Preact 10.27.2 compatibility exports. Ranked hierarchical results, recent/favorite state, autocomplete keyboard selection, modal focus management and translated accessibility comprise a substantial state machine. Reimplementing this library in vanilla JavaScript would duplicate that maintenance and accessibility work. The rest of the application remains vanilla/custom elements; Astro is not required to build it.

The esbuild output inputs attribute 133,132 bytes to chunks containing DocSearch/Preact inputs. This is attribution, not the complete transitive loaded search graph or compressed transfer cost; Checkpoint C must measure reachability before presenting client payload comparisons.

## Configuration and remaining server limitations

Copy `config/public.example.json` to ignored `config/public.json`, set your public API/Supabase values, then rebuild. These values become browser-visible bundle configuration. Pricing supports `PUBLIC_BASE_API_URL`; registration uses the tracked native runtime configuration. Ordinary builds use tracked sources only. `tools/recover-controller-sources.mjs CHECKOUT` is a one-time recovery helper for the pinned upstream source, not a preparation prerequisite.

Recovery of a client controller does not implement its backend. Android keystore and CSR endpoints, device enrollment, authentication and account operations still require compatible services. The older optional `runtime/server.mjs` capability adapter is not automatically compatible with every original `/api/tools/*` URL. Static serving cannot validate those end-to-end operations. No account creation, terms acceptance, private signing upload or device enrollment was performed as a verification shortcut. Certificate conversion browser upload remains unverified.
