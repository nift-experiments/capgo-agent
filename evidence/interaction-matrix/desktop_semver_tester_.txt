			26 heading What "Native Baseline Version" means, Value: 2
				27 text What "Native Baseline Version" means
			28 container
				29 text Native Baseline Version is the native app version sent to Capgo as  version_build  when the device asks the update server for a bundle. In a Capacitor app, that value can come from  CapacitorUpdater.version  in  capacitor.config.* . If that setting is not present, the plugin falls back to the native app version from iOS or Android. Do not assume it is your  package.json  version unless your build copies that value into config or native metadata.
