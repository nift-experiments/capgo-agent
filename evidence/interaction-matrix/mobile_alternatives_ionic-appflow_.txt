					290 text How do App Store credentials compare for native builds?
				291 text Appflow stores your Apple ID and app-specific password to upload binaries. Capgo uses App Store Connect API keys (.p8): scoped, revocable, and independent of personal Apple ID password changes. For cloud builds, credentials are only used in ephemeral environments — not parked on a vendor server indefinitely.

Capawesome has always worked the way Ionic prefers. Partner status is a business relationship, not a technical ranking: Capgo and Capawesome have both moved Appflow customers, so compare the products on their merits.
